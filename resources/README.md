Положите сюда `app.ico` (многоразмерный `.ico`, обычно 16/32/48/256). `CMakeLists.txt` подхватит его автоматически при следующей конфигурации (`cmake -S . -B build ...`) и запечёт как иконку `zkgram.exe` через `app.rc`.

Без `app.ico` сборка не ломается, иконка просто не подключается и используется стандартная иконка exe.
